Privacy Policy

Last updated: November 21, 2026.

PassiveClips is used only by its owner to manage the owner's own channels. When the owner signs in with Google, PassiveClips receives an OAuth token for the owner's YouTube channel. It uses that token only to upload the owner's videos and to read view, like and comment counts and the subscriber count for those videos and channels.

Tokens and statistics are stored only on the owner's own computer. They are never sold, shared with third parties, or used for advertising. No data is collected from anyone else.

PassiveClips's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Access can be removed at any time at myaccount.google.com/permissions, which stops all further access.
